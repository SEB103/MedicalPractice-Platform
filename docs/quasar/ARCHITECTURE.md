# Архитектура и принятые решения

## Реализованный объём

Одна практика, одна врач Dr. Anna Linden, один синтетический пациент Max Mustermann.
Vue 3 Composition API и TypeScript strict; Quasar CLI с Vite; Vue Router; Pinia.
Quasar используется напрямую: QLayout, QHeader, QDrawer, QPage, QCard, QBtn, QInput,
QSelect, QDate, QStepper, QTable, QTabs, QDialog, QBanner, QToggle, QExpansionItem.
Нет iframe, innerHTML-шаблонов, копий страниц для разных тем и внешних CDN.
Roboto, Material Icons и иллюстрация комнаты поставляются вместе со сборкой.

Точные установленные версии зафиксированы корневым package-lock.json.
Quasar CLI 3 требует Vue Router 5; это учтено при разрешении зависимостей.
Node 24.x является целевым runtime этой поставки.

## ADR-001: SPA для текущего прототипа

Hash routing выбран для переносимого статического хостинга и прямого открытия
внутренних страниц без серверного fallback. Vue-страницы загружаются отдельными chunks.
SSR/SSG публичных страниц следует оценить перед production для SEO и доставки контента.
В этой поставке настоящая серверная часть не предусмотрена.

## Данные и сервисы

Pinia хранит роль, тему, световой режим, записи, выбор адреса и настройку уведомлений.
`PatientService` задаёт async-интерфейс list/book/cancel. Страницы вызывают mock-адаптер,
правила изменения записей вынесены в чистые функции и проверены тестами.
Будущий HTTP-адаптер должен сохранить поведение и обработку ошибок на UI.
Данные хранятся под отдельным localStorage-ключом; старый HTML-прототип не мигрируется.
Ошибка или недоступность localStorage не препятствует работе текущей вкладки.
Demo steuern позволяет сбросить данные или сымитировать сбой следующей async-операции.

## Демонстрационные правила — не утверждённые бизнес-правила

- Часовой пояс Europe/Berlin; выбор дня хранится YYYY-MM-DD, времени HH:mm.
- Длительность зависит от услуги (20–60 минут); она сохраняется в записи. Старые записи мигрируют с длительностью 30 минут.
- Рабочие дни Пн–Пт, в пятницу только утро; запись завтра–90 дней включительно.
- Шаг слотов 15 минут; между визитами 10 минут. Учитываются рабочие окна, перерывы, демонстрационные закрытые даты, отпуск и исключения расписания.
- Демонстрационный отпуск: первая полная рабочая неделя следующего месяца. Это пример конфигурации, не реальный календарь праздников.
- Заявка создаётся в статусе pending. Подтверждённый пример есть в seed-наборе.
- Отменять/переносить можно активные записи начиная с завтрашнего дня.
- При переносе исходная запись отменяется только после успешной проверки новой.
- Выход во время async-операции запрещает последующее изменение данных.
- Новые регистрации pending, доступ к кабинету после симулированного approval.
- Профиль редактируется выбором из двух синтетических адресов, без ввода PII.

Локальная роль не защищает данные. Настоящие permissions, конкурентные запросы разных
браузеров, защита от дублей на сервере, аудит, session/CSRF и транзакции нужны в backend.
Повторные запросы внутри одной вкладки проверяются сервисом. Межвкладочная синхронизация
и распределённая блокировка слотов в этой демонстрации не реализованы.

## Темы и оформление

Три конфигурации одной структуры: hausarzt (sage), psychiatry (plum), gemeinschaft (blue).
У последней по-прежнему одна врач. QDark управляет light/dark/auto. Системный режим
реагирует на системную настройку. Цвет primary меняется с режимом; текстовые и фоновые
токены заданы в небольшом общем CSS. Остальные отступы/сетки/контролы — Quasar.
Палитры являются реализационным предложением, а не окончательно утверждённым брендингом.
