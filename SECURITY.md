# Security policy (pre-release)

The codebase is an unimplemented demonstration scaffold. Never enter real patient records, health information or credentials into issues, PRs, screenshots or test fixtures.

Report discovered vulnerabilities privately through GitHub Security Advisories once the repository is registered/configured. Do not assume future production deployment is safe because CI passes.

Real deployment requires authorization review, web security assessment, GDPR/DSGVO evaluation, backup/restore and hosting arrangements.
